## Post-Lab: Delay Comparison of Braun, Booth and Wallace Multipliers

The source supplies the following analytical comparison (an estimate, not a measurement). Stated assumptions: `t_AND` is the AND gate delay, `t_FA` the full-adder delay and `t_HA` the half-adder delay; for the numeric row `t_AND` is taken as about 0.5 `t_FA`, a Booth encoder plus partial-product mux as about 1 `t_FA`, and the final carry-propagate adder as ripple-carry.

| Parameter | Braun Array | Booth (Radix-4) | Wallace Tree |
|---|---|---|---|
| Partial products (4x4) | 4 rows, generated by AND gates | 2 rows, generated by Booth encoder and mux | 4 rows, generated by AND gates |
| Reduction method | Carry-save array, row by row | Carry-save, 1 level for 2 rows | Parallel tree of FA/HA |
| Reduction stages | 3 adder rows (n-1) | 1 | 2 (4 -> 3 -> 2) |
| Final adder | Ripple-carry, 3 bits, part of the array | Ripple-carry / CPA, 8 bits | Ripple-carry CPA, 6 bits |
| Delay equation | T ~ t_AND + (n-1)*t_FA + (n-1)*t_FA ~ t_AND + (2n-2)*t_FA | T ~ t_booth + t_mux + t_FA + CPA | T ~ t_AND + 2*t_FA + (2n-2)*t_FA (CPA) |
| Critical path (4-bit) | t_AND + 6 t_FA | t_enc/mux + t_FA + CPA | t_AND + 2 t_FA + CPA |
| Approx. delay (t_FA units) | ~ 6.5 | ~ 5 to 6 | ~ 4.5 to 5 (with a fast CPA, ~ 3.5) |
| Growth with n | O(n) | O(n) | O(log n) |
| Speed | Slowest | Medium | Fastest |
| Hardware / regularity | Simple, very regular layout | Encoder and mux overhead | Highest wiring complexity, irregular layout |

> **Note.** The table describes a *radix-4* Booth multiplier, but the Booth design supplied in [`09-4bit-Booth-Multiplier`](../09-4bit-Booth-Multiplier/) is a *radix-2* implementation. The Braun array source is also pending (topic 08). The table is therefore reproduced as the author's analysis and has not been checked against the implementations.
